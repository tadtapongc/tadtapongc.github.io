1. The Challenge & Objectives

Coming up with funny, relevant captions for images can be tough. MemeAI was created to automate the process using cutting-edge computer vision models. The goal was to build a full-stack platform where users could instantly generate context-aware memes, share them, and build a personalized collection.

Beyond the AI generation, the challenge lay in handling unpredictable LLM formatting, building a resilient backend for image storage, and seamlessly rendering memes dynamically in the browser.

2. Architecture & Execution

The application leverages the Next.js App Router for server-side API execution and React for complex state management.

  • AI Integration: Uses the Qwen3.6 27B vision model (via Groq API). Images are resized client-side to 800px to optimize payload size, converted to base64, and sent to the API. The model processes a strict system prompt to return an array of 3 top/bottom text pairs in 5 distinct humor styles (Sarcastic, Wholesome, Gen-Z, Cursed, Roast).
  • State & Rendering: Employs React's useReducer to handle complex generation transitions. Memes are rendered dynamically in the DOM using absolute-positioned CSS over the image, allowing instant live updates. When downloading, an off-screen HTML5 <canvas> draws the image and applies ctx.fillText to construct a flattened PNG file.
  • Database & Storage: Utilizes Prisma ORM with PostgreSQL. Instead of relying on external object storage like S3, the application encodes and stores the original imageData directly in the database as base64 blobs, streamlining infrastructure.

Key Engineering Takeaway

"To handle unpredictable LLM JSON outputs from the Qwen vision model, I implemented a 3-layer parsing fallback mechanism: direct JSON parse, aggressive text sanitization, and regex extraction. This ensures the app doesn't crash even if the AI hallucinates markdown tags."

3. Results & Next Steps

The project successfully demonstrates the integration of modern web technologies with advanced 27B parameter vision models. The inclusion of caching headers, optimistic UI updates for likes, and robust database models allows the community feed to remain highly performant.

Future improvements may include personalized user feeds, video meme support, and advanced image editing controls.
