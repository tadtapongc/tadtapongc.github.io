1. The Challenge & Objectives

Managing academic life efficiently is challenging when syllabi, assignments, and study materials are scattered across different platforms. The objective behind Paced was to centralize academic tracking into one intuitive hub.

The system needed to process highly relational data (semesters, courses, topics, deadlines, and markdown notes) rapidly without bogging down the database with constant multi-table join queries.

2. Architecture & Execution

Built with Next.js 14 utilizing the App Router, Paced focuses on a fluid, responsive user experience backed by a unique document-oriented data model.

  • Document-Oriented SQL: Instead of spreading entities across multiple normalized tables, Drizzle ORM leverages PostgreSQL's jsonb type. The entire application state (courses, topics, deadlines) is stored as a single JSON blob per user, seamlessly synced from React Context to the cloud via a custom sync engine.
  • Dashboard Triage Algorithm: The dashboard aggregates data across active courses to prioritize focus. It generates a dynamic 14-day timeline array and categorizes items into Overdue, In-Progress, and Upcoming to help users triage effectively.
  • Secure Markdown Engine: Topics include rich markdown notes parsed using the marked library. A custom Renderer intercepts the HTML generation to inject Tailwind CSS classes (e.g., .md-p). The output is aggressively sanitized with DOMPurify to restrict rendering to a safe subset of tags, preventing XSS attacks.

Key Engineering Takeaway

"Storing the entire state as a single JSONB blob drastically reduced database read/write complexity and latency. Paired with React Context, it allowed me to build an app that feels entirely local and instantaneous, with cloud persistence happening transparently in the background."

3. Results & Next Steps

Paced serves as a unified workspace that replaces disjointed to-do list apps and note-taking silos. The real-time synchronization and document-oriented architecture mean users experience zero load times when navigating between courses and notes.

Future updates aim to integrate calendar exports, collaborative study groups, and AI-assisted study planning based on historical velocity.
